# Adventurer’s Ledger

A desktop character manager with character sheets, inventory, dice rolling, and parchment or dark themes. Characters are stored privately on each player's computer.

## Downloads

[Open releases](https://github.com/MortuusRegem/adventurers-ledger/releases/latest).

- **Windows:** use the `Adventurers-Ledger-Setup-….exe` installer.
- **Mac — Apple Silicon (M1 and newer):** use the `…macOS-arm64.dmg` download.
- **Mac — Intel:** use the `…macOS-x86_64.dmg` download.

Mac builds require macOS 13 or later. Read the [Mac installation guide](macOS/MAC-INSTALL.md), including the first-launch approval steps for this non-notarized build.

## Updates and character files

Use **Rules and help → Check for updates**. Character files are kept separately from the installed application. Use the app's import/export commands to exchange characters between players and platforms.

## MAC version source

The [macOS folder](macOS) contains the Mac source and packaging scripts. The **Mac version** GitHub Actions workflow builds and tests Apple Silicon and Intel versions before publishing their installers. Personal characters and original uploaded PDFs are not included.
